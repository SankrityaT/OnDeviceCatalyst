# Public Research Artifacts

This directory contains only founder-approved public research material:

- Benchmark contracts and schemas.
- Reproducible baseline reports.
- Sanitized literature and ecosystem summaries.
- Released experiment manifests and raw results.
- Reproduction instructions and published artifacts.

Confidential hypotheses, kernels, raw or negative experiments, internal
analysis, and manuscript drafts do not belong in this repository.

Every performance artifact must identify exact hardware, OS, toolchain, model,
model revision, representation, backend revision, configuration, warmups,
repetitions, metrics, and limitations. A result cannot imply universal
superiority beyond the tested lane.
